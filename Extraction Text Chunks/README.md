# Extraction Text Chunks

This component contains Python code used to extract and transform documents into text chunks for downstream processing with Large Language Models (LLMs).

The chunking process was designed to support scalable document processing and to prepare content for embedding and retrieval workflows in GenAI applications. An improved version of the code includes parallelized processing using threading, significantly increasing extraction performance.

This folder includes:
- Standard extraction code
- An improved version of the code with threading for parallel processing
- Adapted and integrated library-based extraction code
