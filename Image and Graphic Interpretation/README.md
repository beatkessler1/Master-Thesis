# Image and Graphic Interpretation

This component investigates limitations of Large Language Models (LLMs) in interpreting complex graphics and diagrams from supply chain documentation.

Different LLMs were tested to compare their performance in extracting structured information from graphical content. An additional approach was evaluated in which graphics were divided into smaller sections to improve interpretation accuracy and completeness.

This folder includes:
- The original document used for testing (Supply Chain Map / Supply Chain Map Decomposition)
- LLM-generated outputs from different models (LLM Extraction Output)
- An analysis comparing the results and assessing output accuracy
