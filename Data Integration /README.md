# Data Ingestion

This component contains Python code used to ingest and preprocess data from multiple SharePoint sources into the Dataiku platform.

The ingestion pipelines were designed to support scalable processing and to consolidate data from several enterprise knowledge repositories. The implementation includes parallelized processing to improve ingestion performance and reduce processing time.

Data sources included:
- Enterprise Solution
- Planner University
- Quality Management Database
- SCM Learning
- Standard Work
